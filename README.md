## ✨ Overview

Moving to a new place, starting college, or visiting an unfamiliar neighbourhood can make it difficult to know where to go. **Local Mind** aims to make local discovery easier by bringing useful places and experiences into one approachable experience.

> **Project goal:** Help people discover places around them and feel more connected to a new locality.
